# Rocket cabin handoff — 14 November 2026

This coordinated user-requested slice adds an authored Ares flight-cabin interior after orbital insertion. `interiors.ts` adds capsule ribs, crew lockers, three labeled NAV / TRAJ / COMMS panels, a pilot seat, harness, and an amber seat marker. `expedition.ts` adds the seat-state hook, a restrained floating astronaut cue and a panoramic forward window with stars and Earth, Moon, Sun, Mars, Venus and Jupiter drifting slowly by. The window remains animated while the player is seated and the engines are idle. The outside cockpit flight view also shows the moving planetary scenery during orbit and transfer. `index.ts` labels the cabin and forwards `WorldAdapter.setCabinSeatState` to the world scene. `SPACECRAFT_SEAT` and `CabinSeatState` are additive shared contracts; App owns task order, proximity, and transfer progression. Sitting no longer advances the journey; a separate “Begin Mars transfer” action starts it when the player is ready.

Validation: not run at the user's request; the user will test. No external assets or packages were added. The floating body is a visual cue; the existing orbit controller still uses its current cabin movement/collision envelope and is not full 6-DOF movement. Rohit retains future App/contracts ownership, Anshu retains physics ownership, Dixit retains UI ownership, and Himamshu retains world ownership after this coordinated slice.
