# World asset provenance

All terrain, station modules, plants, astronaut geometry, paths, labels and materials
in this folder are created procedurally in the project. There are no downloaded
models, image textures, fonts, network asset requests or third-party asset packs.
Text uses the system font. Three.js remains governed by its existing package license.

This is a stylized authored scene, not NASA Mars imagery, a real outpost layout,
terrain reconstruction or scientifically scaled engineering design. Module positions
and collider envelopes follow the team's shared spatial contract.
